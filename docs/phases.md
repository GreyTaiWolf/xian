# 分阶段内容设计（v0.1）

> 总原则：**每个阶段结束都必须是一个可运行、可玩的版本（垂直切片）**，不留半成品坑。
> 依赖顺序：P0 → M0 → M1 → M2 → M3 → M4（M1 与 M2 可并行开发；M4 的内容在各阶段顺手持续做）。

## 阶段总览

| 阶段 | 主题 | 结束时的可玩状态 |
|---|---|---|
| **P0** | 整体框架 + UI 界面系统 | 标题 → 新建世界 → 主界面，全部面板可交互，存档可用 |
| **M0** | 可玩闭环（无 AI） | 移动 → 打怪 → 掉落 → 穿装备的完整刷宝循环 |
| **M1** | 程序化地图 | seed 生成无限灰度世界 + 小地图 + 等级梯度 |
| **M2** | 天道 AI | AI 导演世界事件 + 编年史 + NPC 对话，可降级 |
| **M3** | 内容纵深 | 宗门 / 城镇 / 秘境 / 境界 / 市场 / 离线演化 |
| **M4** | 打磨 | 光柱 / 音效 / 成就 / 世界 Boss / 新手引导 |

---

## P0：整体框架 + UI 界面系统

**目标**：搭出可扩展的工程骨架；UI 界面先行落地。
**前置产出**：`ui/prototype.html` 静态原型（视觉基准）→ 逐屏移植进框架。

### 模块清单

1. **工程骨架**：Vite + TypeScript。目录结构：

```
src/
  core/          # 主循环、事件总线、状态容器、存档、RNG、配置表加载
  world/         # 地图、实体、生成器（M1 起填充）
  systems/       # 战斗、掉落、背包、经济、宗门…（M0 起填充）
  ai/            # 天道导演、prompt、schema 校验、缓存、降级（M2 起填充）
  render/        # Canvas 地形渲染、实体绘制、粒子
  ui/            # 面板框架、主题、组件、各面板
  config/        # 配置表 JSON
  data/          # 存档 / 缓存（运行时）
```

2. **GameLoop 主循环**：固定时间步（60Hz update 与 render 解耦）；暂停 / 倍速；世界时钟推进（现实时间 → 世界日）。
3. **EventBus 事件总线**：emit/on，模块解耦（战斗事件 → 日志 / 音效 / 成就）。
4. **Store 状态容器**：单一状态树 + 变更订阅；**存档 = 状态序列化**。
5. **存档系统**：localStorage + 版本号 + 迁移函数 + 导出/导入 JSON。
6. **RNG**：mulberry32 可播种；每个系统独立随机流（由 seed 派生），保证可复现。
7. **配置表加载器**：`config/*.json` 驱动一切数值，改表不改码。
8. **UI 系统**：面板管理器（切换/栈）、主题变量、组件库（Button / Panel / ProgressBar / SlotGrid / ItemTooltip / Tabs / 公告横幅）。
9. **渲染骨架**：Canvas（地形/实体/粒子）与 DOM（UI）分层；摄像机抽象。

**新增配置表**：`ui.json`（主题、快捷键）。

### 验收标准

- 打开即进标题界面 → 新建世界（占位种子）→ 主界面。
- 8 个面板全部可开/关，tooltip 正常，设置刷新后仍生效。
- 导出/导入存档可用；无 AI key 时全流程可用。

## M0：可玩闭环（无 AI）

**目标**：验证刷宝手感——这是全游戏最难做对的部分，越早越好。

| 模块 | 内容 |
|---|---|
| 固定小地图 | 手写 40×30 tile 测试场 + 碰撞 |
| 玩家 | WASD/点击移动、拾取、交互 |
| 战斗 | 自动回合 tick + 1~2 个手动技能；仇恨/追击 |
| 怪物 | 3 普通 + 1 精英 + 1 首领，等级缩放 |
| 掉落 | 权重表 + 保底计数 + 光柱 + 拾取 |
| 背包 | 网格 / 堆叠 / 移动 / 丢弃 |
| 装备 | 8 部位穿脱，属性实时重算，对比显示 |
| 成长 | 经验 / 升级 / 属性点 |
| 死亡 | 城镇复活，可选掉落惩罚 |

**新增配置表**：`monsters.json`、`items.json`、`drops.json`、`skills.json`。

**验收**：半小时刷宝循环不腻——打怪 → 光柱 → 拾取 → 穿上 → 变强 → 走向更远处。

## M1：程序化地图

- value noise（2D + octaves/fbm）+ 可播种，自写 ~200 行。
- 生成管线：大陆掩膜 → 高度 → 湿度 → 温度 → 河流 → 生物群系 → 灰度渲染。
- chunk 64×64 惰性生成 + LRU 缓存；`generateChunk(seed,cx,cy)` 纯函数。
- 实体落点：城镇/宗门/资源/秘境（规则评分函数）。
- 刷怪：生物群系怪物表 × 距出生点等级梯度。
- 小地图：chunk 灰度快照 + 势力色块。
- 摄像机：平滑跟随 + 视口裁剪。

**新增配置表**：`biomes.json`、`terrain.json`、`factions.json`、`spawns.json`。

**验收**：换 seed 得到不同世界；同 seed 完全一致；探索流畅；出生点有安全区。

---

## M2：天道 AI 接入

- **AI 客户端**：OpenAI 兼容 + 结构化输出 + 超时/重试。
- **Key 管理**：设置面板 + 连通性测试（浏览器本地存储，玩家自带 key）。
- **种子卡生成**（开局，贵模型）+「解读模式」（代码随机 seed → AI 只命名）。
- **状态摘要器**：世界状态 → <800 token 摘要。
- **世界导演**：每世界日 摘要 → LLM → JSON 指令 → schema 校验 → 数值钳制 → 事件执行器。
- **编年史**：追加 / 裁剪 / 史官 UI。
- **NPC**：性格卡 + 好感记忆 + 按需对话。
- **降级**：模板事件库；AI 全挂游戏照跑。

**新增配置表**：`ai-config.json`、`events-templates.json`、`npcs.json`。

**验收**：关掉 AI 完全可玩；开 AI 后每个世界日有事件公告；非法输出被丢弃且无副作用。

---

## M3：内容纵深

- **城镇**：商店 / 铁匠（强化洗练）/ 拍卖 / 任务板 / 传送阵 / 史官。
- **宗门**：加入 / 贡献 / 功法 / 宗门任务 / 宗门战。
- **秘境**：限时副本，天道开启，高掉率。
- **境界**：突破材料 / 成功率 / 失败惩罚 / 压制倍率。
- **经济**：灵石 + 贡献 + 声望三货币；市场；材料合成。
- **任务**：主线（状态机 + AI 文案）/ 日常模板 / 宗门任务。
- **离线快进**：确定性结算 + 离线日志；错过的导演 tick 用模板兜底。

**新增配置表**：`realms.json`、`shops.json`、`sects.json`、`quests.json`、`crafting.json`。

**验收**：完整周循环（刷怪 → 攒资源 → 突破 → 换区域）；离线 24h 回来世界确实变了。

---

## M4：打磨

- 动效：光柱呼吸 / 伤害数字 / 受击闪白 / 死亡消散 / 面板滑入。
- 音效：命中 / 掉落 / 突破 / 世界事件（可关）。
- 成就 + 统计。
- 世界 Boss + 全服公告 + 首杀。
- 新手引导（10 分钟上手）。
- 性能：对象池 / 视口裁剪 / chunk 预算。

**验收**：稳定帧率；新人上手无卡点；有「再来一把」的冲动。

---

## 整体框架 = P0 的全部内容

框架即 P0：GameLoop + EventBus + Store + RNG + 配置表 + UI 系统 + 渲染骨架 + 存档。
M0 开始只是往框架里装「玩法系统」，所以 P0 的接口设计决定后面所有阶段顺不顺。
