# 数值文档（BALANCE）

> 规则：任何改动影响数值/公式/成本/掉落/概率，必须先改这里。配置表与本文档不一致时以配置表为运行时事实、以本文档为策划意图。

## 1. 战斗公式（src/game/stats.ts）

- 伤害：`round(atk × (1 - def/(def+40)) × (0.9~1.1 波动))`，最低 1。
- 暴击：概率 = `crit%`，暴击伤害 ×2。
- 跨境界压制：`1 + 0.25 × (攻击方大境 - 防守方大境)`，钳制 [0.25, 3]。
- 玩家攻击间隔 800ms；怪物攻击间隔 1300ms；普攻射程 1.15 格。
- 脱战回复：受伤 5s 后 生命 +2/s、灵力 +1.5/s。
- 御剑术：耗蓝 30、冷却 6s、倍率 2.2、射程 3.5。

## 2. 成长曲线

- 升级需求：`xpNeed(level) = 40 + level×35`。
- 每级成长：生命 +30、攻击 +6、防御 +4、速度 +0.2；每 5 级额外 暴击 +1、幸运 +1。
- 境界：9 级一大境（炼气/筑基/金丹/元婴/化神/渡劫），小阶段 初期(1-3)/中期(4-6)/后期(7-8)/圆满(9)。
- 圆满后修为封顶（=需求-1），必须突破：材料+灵石+成功率，失败修为折半、心境 -8。
- 突破成功率：`min(0.95, 基础 + 幸运×0.002 + 心境×0.001 + 悟性×0.001)`。
- 飞升（渡劫圆满突破）：等级归 1，基础属性 ×1.15，转世次数 +1。
- 心境：初始 60，升级 +1、突破成功 +5、失败 -8、死亡 -4；标签 清明≥70 / 稳定≥45 / 波动≥25 / 紊乱。
- 悟性：初始 30。

## 4. 装备品级（src/config/items.json grades）

9 档：凡/良/精/灵/玄/地/天/仙/神。
词条数、系数、价格倍率、特效见配置表；词条数值 = `(池min + rng×(池max-池min)) × 品级affixCoeff × 1.35^来源大境`。
强化：玄铁锭×1 + 灵石 50×(plus+1)，成功率 `0.9 - 0.15×plus`，上限 +5，每级主属性/词条 +15%。

## 5. 掉落（src/config/drops.json + loot.ts）

- 普通怪：材料为主，低概率基础装；精英掉装率更高；首领保证掉落且 roll 两次。
- 保底：每 10 击杀必出 pity 池稀有掉落（计数器入档）。
- 秘境：8 击杀内掉落翻倍，两日冷却，筑基解锁。
- 词条只生成在装备（weapon/armor），数量按品级区间。

## 6. 经济

- 货币：灵石（击杀 3~6+怪级 / 任务 / 出售）。
- 商店价格：见 items.json `price`；万宝商会弟子出售 +10%。
- 宗门贡献：普通怪 +1、精英 +5、首领 +20；宗门战期间（紧张度≥80）翻倍。
- 宗门被动：青云剑宗 攻击+5%、血煞魔教 修为+10%、万宝商会 售价+10%。
- 合成：兽皮×3+30 灵石→回灵丹×2；玄铁锭×3+100→玄铁剑；兽皮×2+20→传送符。

## 7. 刷怪与难度（src/config/spawns.json）

- 玩家周围 8~22 格动态维持密度；属性按 `1 + 距出生点/25` 缩放，封顶 ×3（+1 给兽潮）。
- 怪物等级 = 模板 + floor(距离/20)。狼王固定 (85,75)。

## 8. 世界与天道

- 世界日 = 5 现实分钟（ui.json）。
- 天道导演：导演日间隔由设置决定（1/3/0=关闭）；AI 失败/无 key → 模板事件库。
- 指令钳制：关系 delta ±20、兽潮 power 1~4、灵潮 xpMult 0.9~1.3（1~5 日）、传闻 ≤80 字。
- 离线快进：每离线日 修为 +`20+等级×8`、灵石 +10；编年史最多补 3 条模板事件，不调用 AI。
