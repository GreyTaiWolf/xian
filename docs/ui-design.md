# UI 界面设计规范（v0.1）

> 静态原型实现：`ui/prototype.html`（本规范的可视化基准，全部屏幕可交互预览）。
>
> 视觉探索参考：[`ui-reference-gallery.md`](ui-reference-gallery.md)。参考图只用于布局、层级与美术方向，不覆盖本文档的工程约束。

## 1. 设计原则

1. **灰度是舞台，颜色是信息**：地形全灰度；颜色只留给稀有度、势力、敌我、血蓝。
2. **文字即素材**：面板以文字为主、几何图形为辅，零美术成本。
3. **面板化**：所有系统都是可开/关的面板，不打断主视野。
4. **数字用等宽字体**，中文用系统字体。

## 3. 字体

- 中文：`"Microsoft YaHei", "PingFang SC", system-ui`
- 数字/英文：`Consolas, "Cascadia Mono", monospace`（class：`.num`）
- 标题字距：标题界面 14px letter-spacing

## 6. 组件库

| 组件 | 规格 |
|---|---|
| Button | 主（蓝描边）/ 金 / 危险（红描边）/ 小号 sm；hover 提亮 |
| Panel | 标题条 + 内容 + 关闭按钮；右侧滑入 120ms |
| ProgressBar | 高 8px 圆角；血 `#ff5a5a`、蓝 `#58a6ff`、经验/贡献 `#c9a45c` |
| SlotGrid | 背包 8 列；物品格 40px、稀有度色边框、右下角堆叠数 |
| ItemTooltip | 信息卡：稀有度色名称 + 类型/品阶 + 词条（绿）+ 描述 + 售价 |
| Tabs | 底部 2px 主题色指示条 |
| 公告横幅 | 世界事件：顶栏下方滑入 3s |
| 数值行 | `label ─── value(+加成)` 两端对齐 |

## 7. 交互规范

- **键盘**：WASD/方向键 移动；`B`背包 `C`角色 `E`装备 `M`地图 `G`宗门 `T`任务 `J`编年史 `Esc`关闭面板；空格 攻击。
- **鼠标**：点击地形移动；hover 物品/槽位 → 信息卡。
- **动效**：伤害数字上浮渐隐 0.8s（暴击黄色）；光柱呼吸 1.5s；受击闪白 60ms。

## 8. 与框架的衔接

- 原型中的 CSS 变量、组件结构 = 框架 UI 主题与组件的直接来源。
- 面板先以静态 HTML 落地，M0 起逐屏接数据（Store 订阅）。
- 地形视口在原型里是 CSS 网格演示；框架中用 Canvas 实现同一视觉语言。
